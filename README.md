# Air Raid Alerts in Ukraine: Time-Series EDA

## Опис проєкту
Цей міні-проєкт є інструментом для розвідувального аналізу даних (EDA) часових рядів повітряних тривог в Україні. Мета проєкту — виявлення статистичних закономірностей, сезонності та еволюції тактики загроз через аналіз тривалості та частоти сповіщень. Рішення побудоване як MVP для швидкого розгортання та обробки великих історичних масивів даних.

## Структура репозиторію
* `/data/` — директорія для зберігання вхідних даних (історичний архів `full_data.csv` або дамп API `raw_alerts.json`). *Зверніть увагу: масиви даних не додані до репозиторію через обмеження розміру (додано у .gitignore).*
* `eda_alerts.ipynb` — основний робочий простір (Jupyter Notebook), що містить пайплайн з нормалізації даних (обробка NaT та часових поясів), створення нових ознак (Feature Engineering) та інтерактивні візуалізації.
* `fetch_alerts.py` — Python-скрипт для екстракції актуального зрізу активних тривог у режимі реального часу.

## Ключові візуалізовані інсайти
Аналітичний пайплайн автоматично генерує наступні метрики та графіки (Plotly):
1. **Історична динаміка по роках:** Оцінка загальної інтенсивності загроз.
2. **Сезонність та циклічність:** Сумарна кількість тривог за місяцями для визначення періодів пікових навантажень.
3. **Топ-15 локацій:** Області та громади, що зазнали найбільшого акумульованого впливу (за сумарним часом перебування у стані тривоги).
4. **Структура часу доби:** Пропорційний розподіл початку тривог за макро-періодами (ранок, день, вечір, ніч).
5. **Еволюція медіанної тривалості (Defense Data Science Metric):** Моніторинг зміни середнього часу тривоги (month-over-month), що відображає перехід між різними типами загроз (наприклад, від швидкісної балістики до тривалих хвиль БПЛА).
